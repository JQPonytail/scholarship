# 访客版 · 怎么管理访问码（加码 / 废码） 部署好之后，访问码都放在一个叫 `codes.json` 的文件里。你要发码给新朋友，或作废旧码，就改这个文件——**在 GitHub 网页上点几下就行**，不用写代码。 ## 一、加一个新码（发码给新朋友） 1. 打开你的 GitHub 仓库，点进 `codes.json` 文件 2. 点右上角的**铅笔图标**（编辑） 3. 复制最后一条码的**两行**（从 `{` 到 `},`），粘贴到列表里 4. 把 `code` 后面的 6 位数字改成新的（比如 `582940`） 5. `note` 后面改成备注（比如 `给导师`） 6. 点右下角绿色 **Commit changes** 保存 改完保存后，新码**立刻生效**（朋友输这个码就能进，最多等几十秒浏览器刷新）。 ## 二、废掉一个码（朋友用完了 / 不让他进了） 两种办法，任选： - **办法 A（推荐）**：找到那一行，把 `"used": false` 改成 `"used": true`，保存 - **办法 B**：直接把那一整条（从 `{` 到 `},` 两行）删掉，保存 ## 三、字段是什么意思（照着抄就行） ```json { "code": "829417", "expires": 1794384764000, "used": false, "note": "给朋友A" } ``` | 字段 | 什么意思 | 怎么填 | |---|---|---| | `code` | 6 位访问码 | 随便想一个 6 位数字，别跟已有的重复 | | `expires` | 过期时间 | **别自己算**，直接复制旁边现成的那串数字（有效期约 30 天） | | `used` | 是否已作废 | 能用填 `false`，作废填 `true` | | `note` | 备注 | 记一下这码发给谁了，方便你以后找 | ## 四、一个提醒 - 每个码**默认是"一次有效 + 到期自动作废"**：同一台设备用过后不能再用；超过 `expires` 时间也自动失效。 - 想让一个码**永久作废**（哪怕朋友还没用），就按"办法 A"把 `used` 改成 `true`。 - 如果你实在不想自己改，也可以**直接把要加/要删的码告诉我**，我帮你改好并更新。 > 提示：GitHub 网页编辑文件很简单，就是"点铅笔 → 改字 → 点保存"。第一次不熟可以截图问我。
